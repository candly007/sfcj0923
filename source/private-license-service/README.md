# 私有化子授权节点

该服务只服务一张已由主授权开启私有化的卡密，提供激活、租约验证、状态心跳、篡改阻断、解绑、健康检查和本地网页状态页。节点不生成卡密、不保存主授权管理员令牌、不提供远程命令、文件下载或数据库访问。

## 安装

从主授权后台对目标卡密点击“开启私有化”，保存 10 分钟有效的一次性部署码。将 `install.sh` 放到客户服务器，安装器会从固定的主授权地址读取当前发布清单和单文件，不需要手工复制二进制或填写 SHA-256。执行：

```bash
sudo bash install.sh --license-id <卡密ID> --bootstrap-code <一次性部署码> \
  --card '<卡密>'
```

主授权后台会直接生成等价的一条命令，执行后由 `/dev/tty` 提示输入卡密，不把卡密写入 shell 历史：

```bash
curl -fsSL http://主授权IP:5180/private-install.sh | sudo bash -s -- \
  --license-id '<卡密ID>' --bootstrap-code '<一次性部署码>'
```

也可以省略 `--card`，安装器会从终端安全读取；可选 `--version` 只允许安装主授权当前发布的固定版本。安装器先验证主授权签名清单和下载文件 SHA-256，再创建低权限 systemd 服务。服务默认监听服务器所有网卡的 `0.0.0.0:5190`，安装完成会打印服务器公网 IP 访问地址；也可用 `--bind-address <IPv4>` 或 `PRIVATE_LICENSE_BIND_ADDRESS` 指定实际网卡地址（禁止回环地址）。首次登记成功后从 `bootstrap.env` 删除卡密和一次性部署码。插件配置的授权地址填写客户节点地址；公网访问前需在云安全组/防火墙放行 TCP 5190，并建议配置 TLS 反向代理和来源限制。

主授权服务发布端需要配置以下环境变量，并指向已审核的私有节点单文件；哈希在主授权启动时计算一次，版本名由发布流程固定：

```bash
LICENSE_PRIVATE_BINARY_PATH=/var/lib/shunfeng-license/releases/PrivateLicenseService
LICENSE_PRIVATE_BINARY_VERSION=private-20260829-r1
```

清单接口只接受仍未使用且未过期的部署码，并绑定卡密 ID 和版本。下载不会消耗部署码，节点登记成功后部署码立即失效；错误卡密、错误版本、过期或已使用部署码返回 `403`，同一卡密已经登记过私有节点时返回 `409 private_node_already_bound`，安装器会明确提示禁止重复部署。

## 本地后台

网页后台直接输入该私有节点对应的卡密进行验证；服务端只保存卡密 SHA-256，不保存卡密明文，也不再生成或要求节点管理员令牌。卡密通过 `X-Private-License` 请求头发送到当前节点，不发送到主授权。网页显示本节点卡密状态、到期时间、绑定 IP、安装标识、同步时间和本地阻断原因。

主授权关闭私有化、吊销、删除或卡密到期后，节点停止获得新委托；现有委托最长 10 分钟后失效。私有节点网页的“彻底解绑”会清除本地插件安装标识和插件服务器 IP 绑定，下一次通过全部授权和构建校验的激活会原子绑定新服务器；私有节点自身的 `PrivateNodeIp` 不会被清除或改写。每个自然月最多执行 3 次插件解绑，第四次返回 `429 unbind_monthly_limit`。迁移时必须先停止旧服务器插件，再执行解绑并启动新服务器；否则旧服务器仍可能抢先重新激活。主授权网页的普通解绑只清理主授权记录，不代替私有节点本地解绑。
